# PRD: ko-docs-agentic-rag

## 목표
한국어 사내 문서에 대해, 질의 유형에 맞는 도구를 골라 쓰는 Agentic RAG를 만들고 **검색·답변·보안을 각각 수치로 증명**한다. 무엇이 성능을 바꿨는지 한 번에 한 변수씩 측정한 결과표가 핵심 산출물이다.

**주 서사:** 한국어 사내 문서 검색 품질을 **측정으로 개선**했다(분석기·하이브리드 결합·청킹·파서 실험의 사다리 표). **보조 서사:** 에이전트가 **언제** 필요한지 질의 유형별로 증명했다(단순 RAG 대 Agentic RAG), 권한 있는 사내 검색을 **새지 않게** 만들었다(단일 인가 지점, 보안 테스트셋 누설률).

## 사용자
- 가상 IT 서비스 회사(약 200명)의 임직원. 팀·직급에 따라 볼 수 있는 문서가 다르다.
- 외부 에이전트·클라이언트(프로젝트 B의 에이전트, Claude Code 등). MCP로 같은 검색 도구를 쓴다.

## 코퍼스
- **실제 문서:** NIA(한국지능정보사회진흥원) ALIO 공시 내부규정 95개, 원문 무가공·로컬 전용(ADR-002). HWP·HWPX, 조·항·호 구조, 별표 표. 법제처 Open API 구조화 조문을 파싱 정답 텍스트로 쓴다. **최신성 문항의 출처는 실제 개정 이력**(ALIO 개정 버전 파일 + 법제처 연혁, ADR-022)이다.
- **합성 문서:** 시드 데이터(인물·서비스·사건 타임라인·티켓 DB)에서 생성한 회의록·주간보고·장애 보고서·런북·가이드·공지 약 200건과 티켓 약 500행·결재 약 150행. 기간 2025-01 ~ 2026-06.
- **조직:** 플랫폼개발·결제서비스·데이터AI·SRE인프라·정보보안·인사·재무·법무컴플라이언스.
- **권한:** 전사 공개 / 팀 한정 / 제한 3단계. 제한 문서에는 누설 판정용 카나리아 사실을 심는다.
- **식별자:** `PAY-1234`(티켓), `EXP-2026-0412`(결재), `INC-2026-031`(장애), `여비규정 제8조`(조항), `billing-api`(서비스).

## 핵심 기능
1. **질의 유형별 검색 경로:** 식별자 정확 일치, SQL 집계(티켓·결재), 하이브리드 검색(BM25 + k-NN, RRF·정규화). 모두 권한 pre-filter 적용.
2. **Agentic RAG (LangGraph):** 도구 4개(`search_docs`, `lookup_id`, `run_sql`, `get_document`), 가드레일(MAX_STEPS=5, 토큰 상한, 타임아웃), 인용 필수, 근거 없으면 거절. 비교 기준으로 단순 RAG도 같은 부품으로 구현.
3. **MCP 서버:** 같은 도구 4개를 streamable HTTP로 노출. bearer 토큰으로 사용자를 식별하고 서버가 권한을 결정한다. 프로젝트 B의 에이전트가 이 서버의 클라이언트가 된다.
4. **평가 하네스:** 파싱·검색·답변·보안·운영 지표를 산출하고 결과표를 `docs/results/`에 남긴다. 지표 정의는 `docs/EVAL.md`.
5. **질의 유형 라우터 (조건부):** 단순 RAG와 Agentic RAG의 승자가 질의 유형별로 갈리면, 유형을 분류해 둘 중 하나로 보내는 라우터를 제3 시스템으로 추가한다.
6. **데모 GUI (Streamlit):** ① 질의 화면 — 사용자(팀·직급) 전환, 답변, 인용, 도구 호출 트레이스, 비용. 같은 질문을 사용자만 바꿔 던져 허용·거절을 보여준다. ② 결과표 뷰어. `answer()`만 호출하는 얇은 껍데기다.

## 일정과 예산
- **기간:** 목표 6주. **3주차 말에 M5(검색 실험표) 완료 여부를 점검**한다. 늦으면 리랭커 → 업스테이지 비교 → n-gram 분석기 → 고정 길이 청킹 순으로 범위를 줄인다. 단순 RAG 대 Agentic RAG 비교, MCP 서버, 누설률, 신뢰구간은 줄이지 않는다(주장 자체이므로).
- **API 비용:** 상한은 설정값(`MONTHLY_BUDGET_USD`). M1 실측 쪽수 기준 $45로 조정. 생성·평가·파싱 스크립트가 누적 비용을 원장(정가 + 부가세 포함)에 기록하고 상한을 넘기 전에 멈춘다.

## MVP 제외 사항
- 운영용 웹 애플리케이션 (데모 GUI만 제공)
- MCP OAuth 2.1 인증 (데모는 정적 토큰, 실서비스 교체 사항으로 한계에 명시)
- 쓰기 도구 (문서 수정·결재 실행 등. 읽기 전용만 제공)
- 원문 증분 동기화·실시간 인덱싱
- 모델 파인튜닝

## 성공 기준
- 검색 실험표: 전체 조합을 실행하고 사다리 표(주)·제거 실험(보조)·전체 조합(부록)으로, 문서 단위 NDCG@10·Recall@10과 짝 비교 부트스트랩 95% CI를 보고
- 사전 등록한 가설마다 채택/기각과 원인 분석
- 단순 RAG 대 Agentic RAG를 질의 유형별 정답성·지연·비용·단계 수로 비교, 틀린 문항의 실패 원인 분류
- 보안 테스트셋 누설률 0% (in-process 경로와 MCP 경로 모두, 간접 인젝션 포함)
- 채점 모델과 사람 채점의 가중 Cohen's κ ≥ 0.6 (미달 항목은 사람 채점으로 보고)
- 단순 RAG 전체 지연 P95 ≤ 5s (측정 환경 명시, 검색 구간·TTFT·전체 분리)
