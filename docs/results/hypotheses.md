# M4 가설 사전 등록

검색 구현(M5) 전에 가설·판정 대상·판정 방법을 고정한다(ADR-026). 검색·답변 가설의 보고 대상은 골드 test만이며, H6은 별도의 M7 보안 테스트셋으로 판정한다.

## 공통 판정 기준

- 짝 비교 가설은 10,000회 부트스트랩으로 95% 신뢰구간을 계산한다. 95% CI가 0을 포함하지 않으면 채택하고, 포함하면 `판정 보류(차이 입증 못 함)`로 보고한다. H7은 문항이 서로 달라 독립 표본 부트스트랩을 쓴다.
- 유형별 수치는 문항 수가 적어 참고용으로만 보고한다.
- `검색 지표 대상`은 qrels가 비어 있지 않은 identifier·semantic·table·multi_doc·temporal 유형의 골드 test 21문항이다.
- 결과를 본 뒤 가설·판정 대상 문항 수·판정 방법을 바꾸지 않는다. 각 가설에 채택·기각·판정 불가와 원인을 보고한다.

## 가설

| ID | 가설 | 판정 대상(문항 수 고정) | 방법 | 검정력 한계 | 검증 phase |
|---|---|---|---|---|---|
| H1 | nori > standard (문서 단위 Recall@10) | 골드 test 검색 지표 대상 21 | 짝 비교 부트스트랩 | n=21이라 약 0.05 수준 차이는 CI가 0을 포함하기 쉽다 | M5 |
| H2 | hybrid > BM25(nori) (문서 단위 NDCG@10) | 같은 21 | 짝 비교 부트스트랩 | `lexical_mismatch` 태그 부분집합은 기술 통계만(판정하지 않음) | M5 |
| H3 | 구조 청킹 > 고정 청킹 (구간 겹침 적중률) | 같은 21 | 짝 비교 부트스트랩 | H1과 같음 | M5 |
| H4 | 식별자 keyword 정확 일치의 1위 적중률 > 본문 검색 | 골드 test identifier 4 | 짝 비교 부트스트랩 | 4문항이라 사실상 판정 불가. 실버 identifier test 문항으로 방향만 확인 | M5 |
| H5 | Agentic RAG > 단순 RAG (정답성 0~3) | 골드 test identifier+sql+multi_doc 묶음 13 | 짝 비교 부트스트랩(묶음 합산) | 유형별은 기술 통계만. 나머지 유형에서 차이가 없다는 것은 증거 부족일 뿐 동등성 주장이 아니다 | M6·M7 |
| H6 | 누설률 0% (in-process·MCP, 간접 인젝션·존재 누설 포함) | M7 보안 테스트셋 200건 이상 | 관측 누설 건수 | 0/200이면 누설률 95% 상한 약 1.5%(3의 법칙). "0%"는 관측값이지 증명이 아니다 | M7 |
| H7 | 합성 문항 점수 > 실제 문항 점수 (문서 단위 Recall@10) | 골드 test 중 양쪽 출처에 모두 있는 유형(identifier·semantic·multi_doc)만. 합성 n=8, 실제 n=6(고정) | **독립 표본 부트스트랩**(문항이 달라 짝 비교 불가) | 전체 비교(모든 유형)는 유형 구성이 달라(실제=표·최신성 위주, 합성=식별자·다중 위주) 기술 통계로만. 판정 표본이 작아 방향만 기대한다 | M5 |

H7의 판정 문항 수는 split 확정 후 이 파일에 숫자로 고정하며, 그 뒤에는 결과를 보고 바꾸지 않는다.
