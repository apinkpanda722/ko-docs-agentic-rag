## 9. 한계

- 합성 문서는 실제보다 쉽다(ADR-001). 이후 검색·답변 평가는 실제 문서와 합성 문서 결과를 분리해 보고한다.
- JSON 텍스트 원본만 있고 DOCX 표·스프레드시트 같은 문서 형식 다양성 없음(ADR-024).
- 생성 모델의 샘플링 파라미터 미지원으로 동일 요청 재현 불가하며, 생성 결과 캐시로 재현성을 대체한다.
